# Реальний контрольний набір

Фото фігур, намальованих маркером від руки. На цих фото працює весь конвеєр:
сегментація за кумулятивною гістограмою, потім нейромережа. Синтетичні
силуети сегментувати не треба, вони вже бінарні.

## Що намалювати

Щонайменше 60 фото, краще 80:

| Що | Скільки | Назва файлу |
|---|---|---|
| без дефекту | 30 (по 5 кожної фігури) | `01_circle_clean.jpg` |
| відросток (line) | 6 | `31_square_line.jpg` |
| наріст-півколо (bump) | 6 | `37_hexagon_bump.jpg` |
| наріст на ніжці (blob) | 6 | `43_ellipse_blob.jpg` |
| проріз (slit) | 6 | `49_pentagon_slit.jpg` |
| вм'ятина (dent) | 6 | `55_rectangle_dent.jpg` |

- Фігури: `circle`, `ellipse`, `square`, `rectangle`, `pentagon`, `hexagon`. Дефектні розподіліть між різними фігурами.
- Розмір дефекту варіюйте від ледь помітного до великого.

## Як малювати і знімати

1. Аркуш звичайного білого паперу, чорний або темний маркер.
2. **Фігуру зафарбувати повністю й щільно.** Нейромережа бачить силует, тож
   незафарбовані місця всередині вона сприйме як дірки.
3. Нестачу матеріалу (проріз, вм'ятину) малювати як частину контуру: обвести
   фігуру разом із вирізом, потім зафарбувати все, крім нього.
4. Одна фігура на фото, приблизно по центру, займає 30–60 % кадру.
5. Знімати телефоном згори. У кадрі лише папір: ні ручки, ні пальців, ні краю столу.
6. Звичайне кімнатне освітлення без різких тіней від руки чи телефона. Легка
   нерівність освітлення — нормально, так перевіряється сегментація.

Покласти фото сюди, в `article/real/`. Тип дефекту береться з назви файлу.

Трикутник (`triangle`) — окрема група: фігури, якої немає в навчальних даних.

## Аркуші з кількома фігурами

Фото цілих аркушів лежать у `sheets/`, а розмітка — у `sheets.csv` з колонками: аркуш, номер фігури, фігура, дефект. Номери йдуть у порядку читання: рядками згори вниз, у рядку зліва направо. Значення `skip` у колонці дефекту означає, що фігуру пропускаємо. Номери видно на попередньому перегляді.

```
cd experiments
python cut_sheets.py preview ../article/real/sheets <тека для перегляду>
python cut_sheets.py cut ../article/real/sheets ../article/real
python real_eval.py ../article/real ../article/results ../article/figures
```

Вирізані фрагменти зберігаються сюди з назвами `<аркуш>-<номер>_<фігура>_<дефект>.png`, і далі з ними працює `real_eval.py`.
